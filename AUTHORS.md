در `NOTICE.md` ذکر شده و محفوظ می‌ماند.

This repository consolidates Persian RTL patches, the Vazirmatn font, and
build/verify/restore tooling for macOS AI coding harnesses. All harness patches

the upstream Claude Desktop project credited in `NOTICE.md`; that attribution
