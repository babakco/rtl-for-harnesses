# راهنمای کامل پچ RTL و فونت وزیرمتن برای GitHub Copilot (macOS)

> نسخه هدف: `/Applications/GitHub Copilot.app` نسخه **1.1.15** (باندل `com.github.githubapp`)
> تاریخ تهیه: ۵ سپتامبر ۲۰۲۶
> محل پروژه: `harnesses/github-copilot/`

---

## ۱. این پچ چه می‌کند؟

| خواسته شما | رفتار پچ |
|---|---|
| فونت نوشتاری → **وزیرمتن** | فونت Vazirmatn (Regular + Bold، جاسازی‌شده داخل پچ) روی متن چت‌ها و کادرهای ورودی اعمال می‌شود |
| ورودی متن + نمایش متن | هر دو پوشش داده می‌شوند؛ کادر ورودی هنگام تایپ جهت را زنده عوض می‌کند |
| پاراگراف با کلمات فارسی → **RTL** | اگر **حتی یک کاراکتر فارسی/عربی** در پاراگراف باشد، کل پاراگراف راست‌به‌چپ می‌شود — **حتی اگر با کلمات انگلیسی شروع شده باشد** |
| منوی سمت راست (لیست چت‌ها و منوها) | **از RTL مستثنی است** و همیشه LTR می‌ماند تا خوانا بماند و جابه‌جا نشود |
| بلوک‌های کد و فرمول ریاضی | همیشه LTR + فونت مونواسپیس (خوانایی کد حفظ می‌شود) |

---

## ۲. چرا این روش؟ (یافته‌های فنی)

بررسی باینری `/Applications/GitHub Copilot.app/Contents/MacOS/github` نشان داد:

- اپ **نیتیو macOS** است: لینک‌شده به `AppKit` + **`WebKit`** (یعنی رابط کاربری داخل `WKWebView` رندر می‌شود) — نه Electron.
- فرانت‌اند داخل باینری ۳۴۲ مگابایتی embed شده؛ فایل HTML/CSS جدا در Resources نیست.
- امضای `Developer ID (GitHub)` + **Hardened Runtime** فعال است (`flags=0x10000(runtime)`)، پس تزریق مستقیم `DYLD_INSERT_LIBRARIES` روی اپ اصلی **مسدود** است.
- در رشته‌های باینری، شناسه‌هایی مثل `sidebar`، `composer`، `chat-input` و دستور `toggle_sidebar` دیده می‌شود — یعنی چت‌لیست/سایدبار بخشی از همان DOM وب است و با سلکتور می‌شود آن را از قاعده RTL جدا کرد.

**نتیجه:** تنها راه تمیز، هوک‌کردن ساخت `WKWebView` و تزریق یک `WKUserScript` (CSS+JS) به همه وب‌ویوهاست. برای این کار باید Hardened Runtime با **امضای ad-hoc** برداشته شود (نیازی به غیرفعال‌کردن SIP نیست).

## ۴. نصب (قدم‌به‌قدم)

### قدم ۰ — پیش‌نیاز
- macOS با Xcode Command Line Tools (تست‌شده: `clang` و `node` موجود است).
- اپ در مسیر `/Applications/GitHub Copilot.app` نصب باشد.
- از حساب گیت‌هاب خود خارج نمی‌شوید؛ پچ فقط ظاهر را عوض می‌کند.

### قدم ۱ — بیلد
```bash
cd harnesses/github-copilot
./build.sh
```
خروجی موفق: `payload-built.js: ~147 KB` + `JS syntax OK` + `BUILD DONE`.

### قدم ۲ — نصب پچ
```bash
./patch.sh
```
این اسکریپت به ترتیب:
1. اپ را می‌بندد؛
2. یک‌بار از نسخه سالم در `~/CopilotRTLBackup/GitHub Copilot.app` بکاپ می‌گیرد؛
3. dylib و payload را در `Contents/Frameworks/CopilotRTL/` کپی می‌کند؛
4. امضای ad-hoc می‌زند (حذف Hardened Runtime).

### قدم ۳ — اجرا (همیشه با همین لانچر)
```bash
./launch-copilot-rtl.sh
```
> ⚠️ اگر اپ را از Dock یا Spotlight باز کنید، **پچ اعمال نمی‌شود**. همیشه با لانچر بالا اجرا کنید.

### قدم ۳-ب — اعمال مجدد یک‌دستوری (روش استاندارد همیشگی)
```bash
./reapply.sh
```
این اسکریپت متعارف پروژه است و همیشه پچ را **دقیقاً به یک شکل** اعمال می‌کند: اول `build.sh` (جاسازی فونت + چک سینتکس + کامپایل dylib) بعد `patch.sh` (نصب + امضای ad-hoc). بعد از هر آپدیت اپ، همین یک دستور کافی است.

### قدم ۴ — بررسی
- یک چت با متن فارسی بنویسید (حتی جمله‌ای که با انگلیسی شروع می‌شود) → باید راست‌چین با فونت وزیرمتن شود.
- لیست چت‌ها/منوی سمت راست باید چپ‌چین و سر جایش بماند.
- لاگ تزریق را این‌طور ببینید:
```bash
log show --predicate 'process == "github"' --last 5m | grep CopilotRTL
```
باید خط `[CopilotRTL] injected into WKWebView` دیده شود.

## ۵. منطق دقیق RTL (مستند رفتار)

- **محدوده کاراکتر فارسی/عربی:** `0590–05FF` (عبری، بی‌ضرر)، `0600–06FF`، `0750–077F`، `08A0–08FF`، `FB50–FDFF`، `FE70–FEFF` (اشکال نمایشی فارسی).
- **قانون اصلی:** وجود حتی یک کاراکتر از این محدوده در متنِ پاراگراف (بدون احتساب داخل `code`) ⇒ `dir="rtl"` + راست‌چین. شروع انگلیسی تأثیری ندارد.
- **سایدبار/منو/لیست چت:** سلکتورهای `nav, aside, header, [role=navigation/menu/menubar/tree], [class*=sidebar/menu/nav], [data-testid*=sidebar/chat-list/session-list/history]` همیشه `dir="ltr"` می‌گیرند و از پردازش RTL رد می‌شوند.
- **کد و ریاضی:** `pre, code, .katex, mjx-container, math` همیشه LTR + مونواسپیس.
- **زنده‌بودن:** `MutationObserver` استریم پاسخ‌ها را تکه‌تکه پردازش می‌کند؛ رویداد `input` جهت کادر تایپ را لحظه‌ای تنظیم می‌کند.
- **تست خودکار انجام‌شده:** ۶ سناریو (انگلیسی خالص، فارسی، شروع‌انگلیسی+فارسی، فارسی درون‌خطی، آیتم لیست فارسی، پاراگراف فارسی داخل سایدبار) — همه PASS.

## ۷. عیب‌یابی

| مشکل | علت محتمل | راه‌حل |
|---|---|---|
| با لانچر باز می‌شود ولی فارسی RTL نشد | وب‌ویوی آن صفحه دیر ساخته شده یا محتوا iframe جدا با CSP سفت است | لاگ `CopilotRTL` را چک کنید؛ اگر `injected` هست ولی استایل نیست، در راهنما سلکتور جدید اضافه کنید و `./build.sh` + کپی فایل built به `Frameworks/CopilotRTL/` + اجرای مجدد لانچر |
| macOS می‌گوید اپ “damaged” است | Gatekeeper با امضای ad-hoc | `xattr -cr "/Applications/GitHub Copilot.app"` سپس راست‌کلیک ← Open |
| بعد از آپدیت اپ، پچ پرید | آپدیت باندل را بازنویسی کرد | دوباره `./patch.sh` را اجرا کنید (بکاپ سالمِ قبلی سر جایش است) |
| فونت وزیرمتن لود نشد ولی RTL کار می‌کند | base64 خراب یا نسخه built قدیمی | `./build.sh` را دوباره بزنید و خروجی `embedded OK` را ببینید |
| سایدبار جابه‌جا شد | سلکتور نسخه جدید اپ عوض شده | سلکتور جدید را به `SIDEBAR_SEL` در payload اضافه کنید (بخش ۵) |
| خطای `This project already has an active Local workspace` هنگام New session | **رفتار نسخه 1.1.15 است، نه پچ** — اثبات: نسخه اصلی دست‌نخورده (`~/CopilotRTLBackup`) هم دقیقاً همان خطا را داد (تست ۵ سپتامبر ۲۰۲۶). آخرین ساخت موفق سشن با نسخه قبلی (۴ سپتامبر) بود | چت جدید را با **side chat داخل همان سشن باز** بسازید، نه دکمه `+` سطح پروژه (که `create_branch_workspace` می‌فرستد). یا ورک‌اسپیس قبلی را archive/delete کنید بعد New session بزنید. اگر همچنان نشد، به پشتیبانی گیت‌هاب گزارش دهید (رگرسیون نسخه) |
| دکمه آرشیو در UI هیچ کاری نمی‌کند (در دیتابیس `archived_at` خالی می‌ماند) | باگ/رفتار نسخه 1.1.15؛ در لاگ هم هیچ درخواست archive به بک‌اند نمی‌رسد | آرشیو مستقیم در دیتابیس (برگشت‌پذیر): اپ را کامل ببندید، از `~/.copilot/data.db` بکاپ بگیرید، بعد `UPDATE workspaces SET archived_at=..., sessions SET archived_at=...` روی ورک‌اسپیس موردنظر، و اپ را دوباره باز کنید. بکاپ خودکار در `~/CopilotRTLBackup/db/` نگه داشته می‌شود |
| ورک‌اسپیس‌های یک پروژه ناپدید شدند | اگر پوشه پروژه از اپ حذف و دوباره اضافه شود، سطر پروژه با id جدید ساخته و ورک‌اسپیس‌های قبلی با `ON DELETE CASCADE` پاک می‌شوند (سشن‌ها/تاریخچه چت در جدول `sessions` می‌مانند) | جای نگرانی نیست: پروژه تازه صفر ورک‌اسپیس دارد و New session کار می‌کند. برای بازگردانی حالت قبل، از بکاپ `~/CopilotRTLBackup/db/data.db.<timestamp>.bak` استفاده کنید |

## ۸. محدودیت‌ها و ریسک‌ها (صادقانه)

1. **امضای اصلی اپ از بین می‌رود** (ad-hoc). برای امنیت، بکاپ نگه دارید؛ آپدیت خودکار ممکن است امضا را برگرداند و پچ را خنثی کند.
2. اگر گیت‌هاب در نسخه بعدی چت را از WebView به رندر نیتیو منتقل کند، این پچ روی متن چت اثر نمی‌کند (سایدبار/هوک سالم می‌ماند).
3. پچ فقط **ظاهر** را تغییر می‌دهد؛ به داده، لاگین یا صورتحساب دست نمی‌زند.
4. فونت وزیرمتن تحت لایسنس **SIL Open Font License** است (`payload/fonts/OFL.txt`) — استفاده و توزیع آزاد.
